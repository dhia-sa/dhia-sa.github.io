Automated Data Warehouse Pipeline

A single source of truth for a multi-store F&B retail business: 389 scheduled ETL tasks loading POS, ERP and spreadsheet data into a cloud warehouse every day.

Alibaba Cloud AnalyticDB (PostgreSQL) DataWorks Python SQL Power BI

The problem

Sales, finance and operations data lived in separate systems — POS, SAP Business One, JotForm and many manually shared Excel/Google Sheets files. Reporting meant manual exports and copy-paste, and different teams got different numbers.

What I built

  • 389 scheduled daily tasks in DataWorks, running Python jobs on a custom image.
  • Historical backfills plus incremental loads for millions of sales rows.
  • Connectors for POS systems, SAP B1, JotForm, REST APIs and Drive-hosted spreadsheets.
  • A reconciliation process: agree metric definitions with stakeholders first, then check numbers per transaction/document until they tie out.
